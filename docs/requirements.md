# ShopEase – E-commerce Platform

## 1. Project Overview
ShopEase is an e-commerce web application where customers can browse products, add products to their cart, register, log in, and place dummy orders.

## 2. Business Requirements
- Customers can view available products.
- Customers can search for products.
- Customers can register and log in.
- Customers can add products to their cart.
- Customers can place dummy orders without real payment.
- Admin can manage products and inventory.

## 3. User Roles
- Customer
- Admin

## 4. Technology Requirements
- Backend: Java 21 and Spring Boot
- Database: MySQL
- Frontend: HTML and CSS
- Version Control: Git and GitHub
- Containerization: Docker
- CI/CD: Jenkins
- Web Server: Nginx

## 5. DevOps Requirements
- Maintain source code using Git and GitHub.
- Build and test the application.
- Create Docker images.
- Automate deployment using Jenkins.
- Configure Nginx as a reverse proxy.
- Monitor application health.
- Maintain backups and deployment documentation.

## 6. Project Constraints
- Use free and open-source tools.
- Use a local Ubuntu virtual machine for initial deployment.
- No real payment gateway or paid cloud services.
